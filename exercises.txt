# Exercícios Absurdos de PHP para Praticar Tudo

Vou te fornecer uma quantidade absurda de exercícios divididos por tópicos. Prepare-se para muitas horas de prática!

## 1. Sintaxe Básica do PHP

### Variáveis e Tipos de Dados
1. Declare variáveis representando: um nome, uma idade, uma altura, se é estudante ou não, e um array de hobbies.
2. Converta uma string "123" para inteiro e um inteiro 456 para string.
3. Verifique o tipo de 5 valores diferentes usando var_dump().
4. Crie uma variável nula e outra não definida, verifique a diferença entre elas.
5. Use constantes para definir PI, velocidade da luz e gravidade da Terra.

### Operadores
6. Faça operações matemáticas básicas (+, -, *, /, %) com dois números.
7. Compare dois números com todos os operadores de comparação.
8. Use operadores de incremento (pré e pós) em uma variável.
9. Verifique condições combinadas com operadores lógicos (&&, ||, !).
10. Use o operador ternário para verificar se um número é par ou ímpar.

### Estruturas de Controle
11. Crie uma condição if-else que verifica se uma pessoa pode votar.
12. Use switch-case para exibir o dia da semana baseado em um número (1-7).
13. Faça um loop for que exiba números pares de 0 a 100.
14. Use while para calcular o fatorial de um número.
15. Use do-while para pedir input até que o usuário digite "sair".
16. Crie um loop foreach para exibir todos os elementos de um array.
17. Use break para sair de um loop quando encontrar o número 5.
18. Use continue para pular números divisíveis por 3 em um loop.
19. Implemente um sistema de login básico com if-else.
20. Crie um menu de opções usando switch-case.
